## 通信机制

### Electron IPC（主进程 ↔ 渲染进程）

- 使用 `contextBridge` + `ipcMain.handle` / `ipcRenderer.invoke` 模式
- 渲染进程通过 `window.assistant.*` 调用主进程功能
- 禁止渲染进程直接访问 Node.js API

### WebSocket（渲染进程 ↔ Python 后端）

```
渲染进程                          Python 后端
    │                                  │
    │── {"role":"user","content":"..."} ─►│
    │                                  │── 调用 OpenAI API（流式）
    │◄── "token1" ─────────────────────│
    │◄── "token2" ─────────────────────│
    │◄── ...                           │
    │◄── "[DONE]" ─────────────────────│
```

### AI 工具调用流程

```
用户输入
    │
    ▼
AI Service（带系统提示词）
    │
    ├── 普通回复 → 直接流式输出
    │
    └── 工具调用（如截图/点击）
            │
            ▼
        Automation Service
            │
            ▼
        执行系统操作（pyautogui / pywin32）
            │
            ▼
        返回结果给 AI → 继续生成回复

```

## 数据流：Live2D 口型同步

```
WebSocket chunk 到达
    │
    ▼
前端 useWebSocket → 累积文字
    │
    ▼
Web Speech API / 音频分析
    │
    ▼
useLive2D.setMouthOpenY(amplitude)
    │
    ▼
Live2D Cubism SDK 实时更新模型参数
```
